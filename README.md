# Зачёт — подготовка к экзамену

Интерактивный учебный сайт по педагогике и литературе на основе семи конспектов: 17 тем, 75 карточек-вопросов, тесты с пояснениями и повторение ошибок.

## Размещение

Готовый статический сайт. Установка зависимостей и сборка не нужны.

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните.

Все пути относительные: сайт работает и в подпапке GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll.

## Данные

Прогресс хранится в localStorage браузера на текущем устройстве. Карточки и тесты подготовлены по записям лекций; полные PDF с иллюстрациями находятся в папке `sources` и будут публично доступны после публикации.
